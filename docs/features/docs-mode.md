## Docs

Text documents next to boards, like Whimsical docs.
New doc: the "+" menu of a sidebar section. Docs open at `/d/<id>`.

Editor:
- Block editor (BlockNote): headings, paragraphs, bullet, numbered and check lists, toggle lists, quotes, code blocks, tables, images, dividers.
- Type / for the block menu, or Markdown shortcuts (`# `, `- `, `1. `).
- Drag handles to move blocks, a text toolbar for bold, italic, links and colors.
- Live editing with other people's cursors and names.

Blocks of pragmatic's own:
- "Board or doc": a live picture of a board that opens it on double-click (one click when you only view).
- "Callout": a colored note with an icon; click the icon to change the color (blue, yellow, green, red).

Around the editor:
- Editable title, star, presence, Share, version history, copy link, save a copy to Google Drive (Markdown).
- Discussion at the end of the doc.

Claude: `create_doc`, `read_doc` and `write_doc` read and write docs as Markdown.
An embedded board becomes a link in Markdown, a callout a quote.

Not done:
- Comments on a selected part of the text (only the discussion at the end).
